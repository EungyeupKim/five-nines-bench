Five-Nines Bench

Measuring LLM safety out to five nines (99.999%).

Safety failures in LLMs are so rare that five-nines evaluation becomes a major compute bottleneck. Our method does it at a fraction of the cost.

Where the examples sit

    Dataset

    Real user prompts

    Every model is tested on the same real user traffic.

    1. WildChat-4.8M 4.8 million real-world user prompts collected from chatbot conversations. We replay them against any target LLM.
    Method

    How we measure harm

    Evaluation

    Sampling focuses on prompt space where the model is likely to fail.

    1. Find failure modesQwen3-Embedding-8B We embed the WildChat prompts with Qwen3-Embedding-8B and run the cross-entropy method (CEM) in that embedding space. Each round refits a proposal sampling distribution Q toward prompts that made the model respond harmfully, so sampling concentrates on its failure modes.
    2. Run inference The target model generates a response to prompts sampled from failure mode Q. Even closed models can be evaluated.

    Judge

    A response counts as harmful only if all three judge layers flag it.

    1. High-recall screenQwen3Guard A fast first pass that flags anything that might be harmful, so few real harms are missed. Only flagged responses go on to layer 2.
    2. Category rubricgpt-oss-safeguard-120b Judges the user prompt + model response against a detailed rubric for each harm category.
    3. Response-only checkgpt-oss-safeguard-120b Re-reads the model response alone to remove false positives where the harm came from the prompt, not the model (prompt leakage).

    Estimate

    An unbiased estimate of the rare harm rate, with a tight 90% confidence interval.

    1. Importance-weighted CIs90% CI We draw 100,000 prompts from Q, mixed with 10% uniform sampling, and average the importance weights of the responses judged harmful. The 90% confidence interval uses the normal approximation. We repeat this over 10 evaluation seeds and report the median.
